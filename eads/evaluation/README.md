# `eads.evaluation`

**Trace:** Papers 1–4 — reproducible evaluation of EADS pipelines.

Reusable benchmark harness and metric definitions.

- `eads.evaluation.benchmark.Benchmark` — runs a `DecisionPipeline` over a scenario list and emits a report.
- `eads.evaluation.metrics` — `decision_consistency` and `policy_compliance` metrics.

Status: runnable skeleton; remaining metrics and archived benchmark manifests are planned extensions.
