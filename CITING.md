# Citing this work

This repository is an open research companion to the following four EADS papers:

1. *Modernizing Legacy Enterprise Platforms Using LLM-Driven Refactoring and AI-Assisted Architecture Transformation*.
2. *Leveraging Large Language Models and Autonomous Agents for Unstructured Supply Chain Intelligence*.
3. *Reliable LLM-Powered Decision Engines for Large-Scale Supply Chain Operations: Architecture, Safety, and Performance Guarantees*.
4. *Operationalizing Generative and Agentic AI Across Complex Logistics Networks: Architecture, Governance, and Trust Models*.

## Publication status

None of the four papers currently carries a verified DOI in this repository. Earlier revisions
listed DOIs that did **not** resolve to these titles, so they have been removed rather than left
in place: citing an unrelated record is worse than citing none. `data/papers/papers.json` marks
each entry `"status": "unpublished"` with `"doi": null`.

When a paper's publication record is confirmed, add its DOI to `data/papers/papers.json`, set
`"status": "published"`, and mirror it here and in `README.md`. Please verify any DOI against the
publisher's record (for example `https://api.crossref.org/works/<doi>`) before adding it — the
returned `title` and `container-title` must match the paper.

## Citing the repository

If you use the code, benchmarks, or examples, cite the `CITATION.cff` entry for this repository.
