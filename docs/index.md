# Enterprise AI Decision Systems — Research Companion

This site documents the open research implementation accompanying the IEEE EADS papers.

- `research_design.md` — project plan and architecture.
- `tutorials/` — worked examples.
- `examples/` — runnable notebooks and scripts.
- `benchmarks/` — reproducible metric reports.

Run the quickstart:

```bash
pip install -e ".[dev]"
python examples/quickstart.py
pytest
```
